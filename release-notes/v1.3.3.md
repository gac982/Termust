# Termust 1.3.3

Corrección del scrollback al usar la rueda del mouse.

**English:** Termust 1.3.3 fixes scrollback rendering when the mouse wheel is
used.

## Instalación

```sh
flatpak install --user ./termust-1.3.3.flatpak
flatpak run io.github.gac982.Termust
```

## Cambios

- Al desplazar la rueda hacia el scrollback, las líneas se vuelven a dibujar.
  Antes las líneas con índice negativo se descartaban y el panel quedaba vacío.
- La rueda en el prompt sigue sin enviarse a zle y no repinta si el offset no
  cambia.
- Se mantienen el historial bash/zsh y el backup automático de 1.3.1/1.3.2.

## Requisitos

Linux con GNOME/Wayland (X11 funciona como fallback) y Flatpak.

## Assets

- `termust-1.3.3.flatpak`: bundle para instalar con Flatpak.
- `termust-1.3.3.cdx.json`: SBOM CycloneDX.
- `SHA256SUMS`: checksums del bundle, el SBOM y la clave pública.
- `termust-release-key.asc`: clave pública que firma el repo Flatpak.

El bundle no lleva firma propia; la verificación del repo Flatpak se hace con
`termust-release-key.asc`. Los checksums del release están al final de estas
notas.
