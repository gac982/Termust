# Termust 1.4.0

Pestañas que muestran el directorio y el programa en ejecución, historial que
sobrevive a reinicios y gráficos de btop/htop alineados.

**English:** Termust 1.4.0 shows the running program in the tab, persists the
command history across restarts and fixes btop/htop graph alignment.

## Instalación

```sh
flatpak install --user ./termust-1.4.0.flatpak
flatpak run io.github.gac982.Termust
```

## Cambios

- La pestaña muestra el nombre del directorio en el prompt y el del programa
  mientras corre (`btop`, `vim`, `cargo`…). Un nombre manual sigue teniendo
  prioridad; la ruta completa queda en el tooltip.
- El historial de comandos de la sesión se guarda en
  `~/.local/state/termust/history.jsonl`: sobrevive a cerrar la app o reiniciar
  aunque el shell no llegue a volcar su propio historial.
- Los gráficos braille de btop/htop y el dibujo de cajas ya no se desalinean:
  los glifos ausentes en la fuente usan un fallback monoespaciado y cada celda
  se pinta en su columna.
- Se mantienen el scrollback con rueda, el historial bash/zsh y los backups
  automáticos de 1.3.x.

## Requisitos

Linux con GNOME/Wayland (X11 funciona como fallback) y Flatpak.

## Assets

- `termust-1.4.0.flatpak`: bundle para instalar con Flatpak.
- `termust-1.4.0.cdx.json`: SBOM CycloneDX.
- `SHA256SUMS`: checksums del bundle, el SBOM y la clave pública.
- `termust-release-key.asc`: clave pública que firma el repo Flatpak.

El bundle no lleva firma propia; la verificación del repo Flatpak se hace con
`termust-release-key.asc`. Los checksums del release están al final de estas
notas.
