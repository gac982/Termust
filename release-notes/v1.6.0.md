# Termust 1.6.0

Menú contextual con el mouse, copiar/pegar desde el terminal y Shift+Enter
dentro de apps de pantalla completa.

**English:** Termust 1.6.0 adds a right-click Copy/Paste menu and makes
Shift+Enter insert a newline inside full-screen TUIs.

## Instalación

```sh
flatpak install --user ./termust-1.6.0.flatpak
flatpak run io.github.gac982.Termust
```

## Cambios

- Click derecho en el terminal abre un menú con Copiar y Pegar. Copiar se
  habilita solo si hay selección; Pegar respeta bracketed paste.
- El botón derecho queda reservado para Termust aunque la TUI pida reporte de
  mouse (btop, OpenCode, vim). Esas apps siguen recibiendo click izquierdo,
  arrastre y rueda.
- Click medio pega la selección primaria.
- `Shift+Enter` inserta un salto de línea también dentro de TUIs que usan
  bracketed paste (OpenCode, Claude Code), no solo en el prompt del shell.
- Se mantienen los atajos editables, las pestañas con el programa en ejecución,
  el historial persistente y los gráficos de btop/htop de 1.5.0.

## Requisitos

Linux con GNOME/Wayland (X11 funciona como fallback) y Flatpak.

## Assets

- `termust-1.6.0.flatpak`: bundle para instalar con Flatpak.
- `termust-1.6.0.cdx.json`: SBOM CycloneDX.
- `SHA256SUMS`: checksums del bundle, el SBOM y la clave pública.
- `termust-release-key.asc`: clave pública que firma el repo Flatpak.

El bundle no lleva firma propia; la verificación del repo Flatpak se hace con
`termust-release-key.asc`. Los checksums del release están al final de estas
notas.
