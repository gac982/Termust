# Termust 1.5.0

Atajos de teclado editables, salto de línea con Shift+Enter y copiar/pegar en
el mismo mapa de atajos.

**English:** Termust 1.5.0 makes every shortcut editable, adds Shift+Enter for
a line break and routes copy/paste through the same keymap.

## Instalación

```sh
flatpak install --user ./termust-1.5.0.flatpak
flatpak run io.github.gac982.Termust
```

## Cambios

- Panel de atajos editable (menú → Keyboard shortcuts o `Ctrl+Shift+?`): clic
  en una fila y se presiona la combinación nueva. Si ya está en uso se rechaza
  con un aviso que nombra la acción que la tiene.
- Restablecer por atajo y «Reset all» de fábrica; los cambios se guardan en
  GSettings y sobreviven reinicios y actualizaciones.
- `Shift+Enter` inserta un salto de línea sin ejecutar. En TUIs de pantalla
  completa sigue siendo un Enter normal.
- Copiar/pegar (`Ctrl+Shift+C`/`Ctrl+Shift+V`) usan el mapa editable.
- `Ctrl+1…9` para cambiar de pestaña quedan fijos y fuera del panel.
- Se mantienen las pestañas con el programa en ejecución, el historial
  persistente y los gráficos de btop/htop de 1.4.0.

## Requisitos

Linux con GNOME/Wayland (X11 funciona como fallback) y Flatpak.

## Assets

- `termust-1.5.0.flatpak`: bundle para instalar con Flatpak.
- `termust-1.5.0.cdx.json`: SBOM CycloneDX.
- `SHA256SUMS`: checksums del bundle, el SBOM y la clave pública.
- `termust-release-key.asc`: clave pública que firma el repo Flatpak.

El bundle no lleva firma propia; la verificación del repo Flatpak se hace con
`termust-release-key.asc`. Los checksums del release están al final de estas
notas.
