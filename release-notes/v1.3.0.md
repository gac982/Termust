# Termust 1.3.0

Interfaz multiidioma completa: inglés como idioma fuente, traducción al español
y selector de idioma en Preferencias. También corrige el orden del historial
para mostrar primero los comandos más recientes.

**English:** Termust 1.3.0 ships a complete multilingual interface with English
as the source language, a Spanish translation and a language selector in
Preferences. The command history now shows the most recent commands first.

## Instalación

```sh
flatpak install --user ./termust-1.3.0.flatpak
flatpak run io.github.gac982.Termust
```

## Cambios

- Interfaz completa en inglés y español; los locales sin traducción caen a
  inglés.
- Preferencias → General → Language (`System`, `English`, `Español`); el cambio
  se aplica al reiniciar.
- Historial: últimos comandos primero; elegir uno viejo no lo mueve al
  principio.
- Capturas del README regeneradas en inglés.

## Requisitos

Linux con GNOME/Wayland (X11 funciona como fallback) y Flatpak.

## Assets

- `termust-1.3.0.flatpak`: bundle para instalar con Flatpak.
- `termust-1.3.0.cdx.json`: SBOM CycloneDX.
- `SHA256SUMS`: checksums del bundle, el SBOM y la clave pública.
- `termust-release-key.asc`: clave pública que firma el repo Flatpak.

El bundle no lleva firma propia; la verificación del repo Flatpak se hace con
`termust-release-key.asc`. Los checksums del release están al final de estas
notas.
