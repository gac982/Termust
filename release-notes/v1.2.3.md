# Termust 1.2.3

Terminal para GNOME escrita en Rust con GTK4 y libadwaita. Esta versión
incluye el app ID corregido (`io.github.gac982.Termust`) y los arreglos de
rueda/scrollback e historial de las versiones 1.2.1–1.2.3.

**English:** Termust is a terminal for GNOME written in Rust. This release
ships the corrected app ID and the scrollback/history fixes.

## Instalación

```sh
flatpak install --user ./termust-1.2.3.flatpak
flatpak run io.github.gac982.Termust
```

## Requisitos

Linux con GNOME/Wayland (X11 funciona como fallback) y Flatpak.

## Assets

- `termust-1.2.3.flatpak`: bundle para instalar con Flatpak.
- `termust-1.2.3.cdx.json`: SBOM CycloneDX.
- `SHA256SUMS`: checksums del bundle, el SBOM y la clave pública.
- `termust-release-key.asc`: clave pública que firma el repo Flatpak.

El bundle no lleva firma propia; la verificación del repo Flatpak se hace con
`termust-release-key.asc`. Los checksums del release están al final de estas
notas.
