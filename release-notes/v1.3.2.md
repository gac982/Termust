# Termust 1.3.2

Corrección de persistencia de sesión: las pruebas y los arranques con
`--no-restore` ya no pueden pisar las pestañas, paneles y directorios reales.

**English:** Termust 1.3.2 fixes session persistence so tests and
`--no-restore` debug runs cannot overwrite the user's real tabs and panes.

## Instalación

```sh
flatpak install --user ./termust-1.3.2.flatpak
flatpak run io.github.gac982.Termust
```

## Cambios

- `--no-restore` y los hooks de test no guardan la sesión.
- La app sigue guardando la sesión normalmente al usarla y al cerrar.
- Se mantienen el historial bash/zsh y el backup automático de 1.3.1.

## Requisitos

Linux con GNOME/Wayland (X11 funciona como fallback) y Flatpak.

## Assets

- `termust-1.3.2.flatpak`: bundle para instalar con Flatpak.
- `termust-1.3.2.cdx.json`: SBOM CycloneDX.
- `SHA256SUMS`: checksums del bundle, el SBOM y la clave pública.
- `termust-release-key.asc`: clave pública que firma el repo Flatpak.

El bundle no lleva firma propia; la verificación del repo Flatpak se hace con
`termust-release-key.asc`. Los checksums del release están al final de estas
notas.
