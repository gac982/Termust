# Termust 1.3.1

Corrección del historial de comandos para bash y zsh, y backup automático de
configuración, sesión y datos de la app.

**English:** Termust 1.3.1 fixes command history for bash and zsh and adds an
automatic backup of settings, session and app data.

## Instalación

```sh
flatpak install --user ./termust-1.3.1.flatpak
flatpak run io.github.gac982.Termust
```

## Cambios

- El comando aparece en el historial al empezar a ejecutarse, incluso si sigue
  corriendo (`ping`) o se interrumpe con Ctrl+C.
- Los comandos de la sesión se muestran antes que el historial importado de la
  shell; el modal se refresca y mantiene los más recientes primero.
- Bash captura desde `PS0`; zsh sigue usando `preexec`. Ambos probados.
- Backup automático en `~/.local/share/termust/backups` de settings, sesión,
  vault y temas importados, conservando las últimas 5 copias.

## Requisitos

Linux con GNOME/Wayland (X11 funciona como fallback) y Flatpak.

## Assets

- `termust-1.3.1.flatpak`: bundle para instalar con Flatpak.
- `termust-1.3.1.cdx.json`: SBOM CycloneDX.
- `SHA256SUMS`: checksums del bundle, el SBOM y la clave pública.
- `termust-release-key.asc`: clave pública que firma el repo Flatpak.

El bundle no lleva firma propia; la verificación del repo Flatpak se hace con
`termust-release-key.asc`. Los checksums del release están al final de estas
notas.
